# AI 助手教程：让大模型帮你查数、答问、沉淀知识

平台内置 **AI 助手** 模块（菜单：**AI 助手**，`/ai`）：自然语言查数据（智能问数）、
基于平台文档/业务资料的问答（知识库）、通用对话，以及管理员侧的提供商与配额管理。

> 前置：本篇是三篇教程的最后一篇（[上手教程](tutorial.md) → [数据分析](analytics-tutorial.md) →
> [增长闭环](growth-tutorial.md) → 本篇）。AI 功能依赖外部大模型服务，**管理员先配提供商**才能用。

## 一、管理员准备：配模型提供商（一次性）

菜单：**AI 助手 → 模型提供商**（`/ai/providers`）

1. 新建提供商：填名称、模型名（model_name）、API 地址（base_url）与 API Key；
   本地部署模型填 local_host（如 Ollama/私有推理服务），不外呼公网；
2. 保存后点**连通性测试**（TestConnection）——通了再往下走，不通先查 Key/网络出口；
3. 可为不同用途建多个提供商（如问数用高性能模型、闲聊用便宜模型），并设置 system_prompt 定制人设。

**用量与配额**（`/ai/usage`）：按租户维度看调用量汇总（GetUsageSummary），
管理员可设置租户配额（SetTenantQuota）防止失控消费——多租户部署时这是必配项。

## 二、智能问数：自然语言查行为数据

菜单：**AI 助手 → 智能问数**（`/ai/query`）

**示例问法**（对应 [增长闭环教程](growth-tutorial.md) 的电商场景）：

```
最近 7 天 view_product 到 pay_success 的转化率是多少？
上个月各渠道的注册用户数排行
昨天哪些事件的量比前天下降超过 50%？
```

- 它把自然语言翻译成平台分析查询（对应 25 个分析模型的口径），直接给数给图；
- 回答的口径以[数据分析教程](analytics-tutorial.md)里讲的口径体系为准——**问数结果的
  交叉验证方法**：同一问题在对应分析页面手工跑一遍，数字对得上才可信；
- 问不出来/问错时，把问题拆细（限定时间范围 + 明确事件名 + 明确维度），事件名与
  [事件 Schema](sdk_integration.md) 登记名一致成功率最高。

## 三、知识库：让 AI 用你的资料回答

菜单：**AI 助手 → 知识库**（`/ai/knowledge`）

1. 新建知识库（按用途分库：如「埋点规范」「运营 SOP」「产品 FAQ」）；
2. 上传文档（UploadDoc/UploadDocFile，内容或文件）；
3. 提问时 AI 基于库内内容检索作答（Search 检索增强），适合两类场景：
   - **新人自助**：埋点怎么命名、漏斗口径怎么定义——把规范文档入库，新人直接问；
   - **运营沉淀**：把历史活动结论、常见问题入库，问答不随人员流失。

> 知识库答的是"平台怎么用/业务约定是什么"；查"业务数据是多少"用智能问数——两类问题别混。

## 四、AI 对话：通用助手

菜单：**AI 助手 → AI 对话**（`/ai/chat`）

流式对话（server-streaming，逐字出答案）。对话历史在会话列表中留存（Conversation/Message），
可继续追问。典型用法：

- 让 AI 解释某个分析模型的口径定义；
- 把漏斗结果贴进来，让 AI 帮忙起草流失分析结论；
- 结合知识库内容做开放讨论。

## 五、把三篇教程串起来用

| 场景 | 组合 |
|---|---|
| 日常看数 | 数据分析页面手工查 + 智能问数快问快答 |
| 周会汇报 | 定时报告出数 + AI 对话起草结论 |
| 新人上手 | 本教程系列 + 知识库（把三篇教程 PDF/URL 入库，新人可直接问） |
| 异常排查 | 异常检测定位 + 智能问数多口径追问 + 告警回看 |

## 六、坑与提示

- **提供商未配/不通**：三个 AI 页面都会不可用——先做第一节，TestConnection 通过是总开关；
- **配额 401/限流**：多租户部署检查租户配额设置（`/ai/usage`），个人调试被限额找管理员提额；
- **问数口径存疑**：AI 给的数与手工分析对不上时，以分析页面口径为准并把准确问法反馈给
  团队（自然语言解析依赖事件命名规范——这也是 [事件 Schema 登记](sdk_integration.md) 的价值）；
- **Key 安全**：提供商 API Key 是租户级敏感凭据（界面只回显 hint），不要写进前端代码或公开仓库。
